# OpenSEO workflow for Feed Flow

OpenSEO is incorporated as a pinned local checkout at `../open-seo`, from `every-app/open-seo` revision `4fa42c879fd26657aec3472dcf44f08226816df3`.

## What works now

- `npm run seo:audit` checks every sitemap page for missing metadata, canonical mismatches, broken internal links and anchors, missing image alt text, invalid JSON-LD, retired affiliate claims and required homepage sections.
- `seo/content-map.json` maps distinct search intents to dedicated pages using OpenSEO's keyword-clustering workflow. It deliberately makes no search-volume or ranking claims.
- `seo/openseo-context.json` contains the business, audience, positioning and goal context to reuse when the hosted or self-hosted OpenSEO project is connected.
- `seo/technical-audit.json` is regenerated by the audit command.
- `seo/search-evidence.json` separates public search-result observations from metrics that require live providers.
- `seo/ai-discovery.json` records crawler access and neutral prompts for a future OpenSEO AI Visibility tracker; it does not claim observed AI answers.
- `npm test` verifies every sitemap page at desktop and mobile breakpoints, image loading, navigation, review localization and the ambassador form.

## Connect live SEO data

OpenSEO's keyword research, rank tracking and live site-audit tools require an OpenSEO project and DataForSEO credentials. Follow `../open-seo/README.md` and `../open-seo/docs/DATAFORSEO_API_KEY.md`. Keep credentials in OpenSEO's own secret configuration, never in this website repository. Connect Google Search Console in the OpenSEO project for first-party queries, pages, impressions and clicks.

Until that connection exists, the local audit is technical validation only, not a live keyword or traffic audit.
